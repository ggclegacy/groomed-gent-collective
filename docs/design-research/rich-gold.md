# Rich antique gold — September 2026

Replaces accumulated yellow and pale gold literals across the application styles, chart SVGs and sign-in accent. Obsidian and purple values are preserved.

The final shared tokens are readable antique gold `#B58E60`, a restrained highlight `#BD9465`, deep metal `#A67E4D`, and shadow `#76512F`. The metallic gradient varies direction and intensity without white stops. Buttons keep a dark text color across the entire gradient. Large Command lettering uses a subtle metal reflection; small text stays solid. Forced-color modes restore system colors.

Calculated WCAG contrast examples: main gold on `#201329` is 5.90:1; highlight on `#291435` is 6.09:1; darkest button stop against `#100C09` text is 5.30:1. These token checks are not a claim that every rendered state has been audited.

No behavior, layout, dependency, schema or integration changes. Existing rounded geometry, lighting and motion remain.
