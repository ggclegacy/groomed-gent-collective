# Polished deep materials

The latest feedback distinguishes deep pigment from reflected light. The prior pass brightened large color areas; this revision darkens those areas and concentrates the shine.

Gold base #B99258, metal shadow #A37A40, restrained highlight #C8A166. A narrow #E0B978 specular band is reserved for metal reflection. Purple planes move to aubergine #2C103E and #371348 with darker shaded edges. There are no white gold stops.

Existing pointer reflections now use a narrow bright band with an adjacent darker falloff. Button and large-letter gradients repeat this metal response. Large gold type retains a restrained glow; small text retains solid color for legibility. Cassius keeps its illuminated core with deeper violet body color. Motion, geometry, keyboard behavior and reduced-motion controls are preserved.

No dependencies, schemas or functional flow changes. Verification covers application lint, existing tests, production compilation and live HTTP/asset checks; no rendered visual or device-performance audit is claimed.
